## 🧑‍💻 About Me

C/C++ 기반으로 **Windows 환경**에서 **실시간 3D 그래픽스**와 **네트워크 프로그래밍**을 파고드는 개발자입니다.
"엔진 밑바닥"에 관심이 많아서, 라이브러리부터 그래픽스 파이프라인까지 직접 만들어보며 원리를 파고드는 걸 좋아합니다.

### 🔨 무엇을 하나요?

- 🧩 C/C++을 이용한 다양한 고성능 라이브러리 개발
- 🎮 DirectX 11 기반 래스터라이저 컴퓨터 그래픽스 시뮬레이션 데모 개발
- 🖥️ Windows 환경에서 다양한 소프트웨어 개발
- 🕹️ Windows 플랫폼 게임 개발
- 🌐 게임 플레이에 적합한 실시간 네트워크 기능 개발
