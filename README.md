## 🧑‍💻 About Me

C/C++ 기반으로 Windows 플랫폼에서 게임, 실시간 3D 그래픽스, 네트워크 기능을 개발하는 프로그래머입니다.  
C++20을 즐겨 사용하며, GPGPU 기술에도 관심이 많습니다.

### 🔨 무엇을 할 수 있나요?

- 🧩 C/C++ 고성능 라이브러리 개발
- 🎮 DirectX 11 을 이용한 3D 컴퓨터 그래픽스 작업
- 🖥️ Windows 환경에서 다양한 소프트웨어 개발
- 🕹️ Windows 플랫폼 게임 개발
- 🌐 게임 플레이에 적합한 실시간 네트워크 기능 개발
