## 🧑‍💻 About Me
게임을 만들어 배포한 경험에서 출발해, C++로 엔진과 라이브러리, 개발 도구를 만들어 왔습니다. 새로운 기술은 직접 구현하며 익히고, 디버깅을 통해 원인을 분석하여 해결하며, 유지보수와 확장이 가능한 구조를 설계하는 것을 고민합니다. 팀 개발과 코딩 교육·운영을 경험하며, 서로의 상황을 공유하고 필요한 일을 함께 맡는 방식으로 일해 왔습니다.
